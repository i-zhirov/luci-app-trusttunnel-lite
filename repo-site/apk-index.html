apk repository — luci-app-trusttunnel-lite

OpenWrt 25.12+ (apk). One signed repository per CPU family — the client package is labeled with the family arch (x86_64, aarch64, armv7, mips, mipsel), and install.sh adds the family to the device's /etc/apk/arch so apk accepts it on every subtarget of the family. Repository URL for the router (the family is the device's CPU family, e.g. aarch64 for any aarch64 device):

https://i-zhirov.github.io/luci-app-trusttunnel-lite/apk/<family>/packages.adb

Public signing key:

  • key-build.pub — public signing key

Families (each directory holds the noarch LuCI packages and the family's TrustTunnel client build):

  • x86_64
  • aarch64
  • armv7
  • mips
  • mipsel
