# Issue TT-04: gen-config (client.toml generator)

- **Status**: Validated
- **PRD**: `../../prd.md`
- **Blocked by**: TT-02
- **Effort**: S–M
- **Files**: `packages/luci-app-trusttunnel/root/usr/libexec/trusttunnel/gen-config`,
  `tests/test_gen_config.sh`

## Context

`gen-config` was inherited (comments translated; the extra-exclusions
source removed; the `esc()`/`array_from_stdin()` awk helpers, the
`emit_certificate()` function and the TOML heredoc template are inherited
expression). It generates the `client.toml` consumed by the Apache-2.0
TrustTunnel client binary — the output is a hard contract with an external
program and must be byte-identical to today.

## Contract to reproduce

- Usage: `gen-config <records-file> [pem-file]`; reads records via the
  sourced `records.sh` (`TT_RECORDS` from `$1`); sources with
  `TT_LIBDIR="${TT_LIBDIR:-$(dirname "$0")}"`.
- Dies with `gen-config: <message>` on stderr and exit 1 when required
  records are missing: `endpoint.hostname`, `endpoint.username`,
  `endpoint.password`, and at least one `endpoint.address`.
- Emits on stdout (exact key set, values, and order):
  - header comment `# Generated by luci-app-trusttunnel. Do not edit:
    changes are overwritten.`
  - `loglevel = "<main.log_level|info>"` (TOML-escaped)
  - `vpn_mode = "<general|selective>"` — NOT fixed: resolved from the
    assigned routing profile (see below); default/legacy is `general`
  - `killswitch_enabled = false` (fixed — the package's blackhole is the
    killswitch)
  - `post_quantum_group_enabled = <true|false>` (from `endpoint.post_quantum`,
    default true — booleans are emitted lowercase `true`/`false`)
  - `exclusions_tcp_early_ack_enabled = true` (fixed)
  - `exclusions_preresolve_enabled = true` (fixed)
  - `exclusions = [...]` — source depends on the profile resolution below
  - `[endpoint]` with `hostname`, `addresses = [...]` (all
    `endpoint.address` values), `has_ipv6 = <true|false>` (default true),
    `username`, `password`, `custom_sni = "<endpoint.custom_sni|"">"`
    (TOML-escaped, always emitted), `client_random =
    "<endpoint.client_random|"">"` (TOML-escaped, always emitted),
    `skip_verification = <true|false>` (default false),
    `certificate = '''…'''` (multi-line literal from the PEM file
    via `awk 1` normalization; the literal `certificate = ""` when no PEM
    file), `upstream_protocol = "<endpoint.protocol|http2>"`,
    `anti_dpi = <true|false>` (default false), `dns_upstreams = [...]`
  - `[listener.tun]` with `included_routes = []`, `excluded_routes = []`
    (deliberately empty — routing is owned by the package), `mtu_size =
    <network.mtu|1350>` (bare number), `change_system_dns = false` (fixed)
- Routing profile resolution (mirrors the GUI client; the profile is
  resolved by name in uci-export and arrives under `routing_profile.*`):
  - `endpoint.routing_profile` set AND `routing_profile.name` matches it:
    - `routing_profile.mode` == `bypass` → `vpn_mode = "selective"`,
      `exclusions` = `routing_profile.vpn_rules` values
    - `routing_profile.mode` == `vpn` → `vpn_mode = "general"`,
      `exclusions` = `routing_profile.bypass_rules` values
    - `routing_profile.mode` is any OTHER value (unknown mode) → the
      legacy fallback branch applies: `vpn_mode = "general"`,
      `exclusions` = `domains.direct` values (the code's `case` only
      special-cases exactly `bypass`/`vpn`; the plan's unknown-mode
      fixture pins this)
  - Otherwise (no assignment, or stale reference — the named profile was
    deleted/renamed): legacy fallback → `vpn_mode = "general"`,
    `exclusions` = `domains.direct` values. Must NOT fail and must NOT
    emit an empty exclusion list on a stale reference.
  - While a profile IS assigned, `domains.direct` must NOT leak into the
    output.
- TOML escaping for scalar strings: backslash → `\\`, double quote → `\"`;
  the array builder escapes each item the same way. No `device_name`, no
  `use_existing`, no other keys (the client silently ignores invented
  keys — they were removed deliberately).
- Executable bit `100755`.
